# LocalChat
LocalChat — лёгкое настольное приложение на Python и Tkinter для общения с локальными языковыми моделями через LM Studio. Не требует облачного API-ключа и не использует внешние Python-библиотеки.

Программа обращается только к локальному адресу http://127.0.0.1:1234/v1.
Возможности
- Чат на русском языке с моделями, доступными в LM Studio.
- Выбор модели, создание нового диалога, сохранение переписки в .txt.
- Копирование и вставка через Ctrl+C, Ctrl+V, контекстное меню и кнопки.
- Настраиваемый сетевой тайм-аут: 2, 5, 10, 20 или 30 минут.
- При наличии статистики API — отображение токенов и приблизительной скорости ответа.
- Прикрепление локального .py-файла к вопросу.
- Запрос на исправление Python-кода с просмотром различий перед записью.
- Создание резервной копии перед подтверждённой заменой файла.
Требования
- Python 3.9+ с модулем Tkinter.
- LM Studio с загруженной совместимой моделью.
- Запущенный локальный сервер LM Studio на порту 1234.
Не требуется pip install.
Быстрый старт
1. Открой LM Studio, загрузи модель и запусти локальный сервер (обычно Developer → Start Server).
2. Скачай LocalChat_LMStudio.py.
3. Запусти его двойным щелчком, через IDLE (F5) или командой:
   python LocalChat_LMStudio.py
4. В окне LocalChat нажми «Обновить», если модель не появилась автоматически.
5. Напиши сообщение и нажми «Отправить» или Ctrl+Enter.
Для проверки сервера можно открыть в браузере http://127.0.0.1:1234/v1/models.
Исправление Python-кода
1. Нажми «Выбрать .py...».
2. Напиши в поле ввода, что требуется изменить.
3. Нажми «Исправить .py по запросу».
4. Проверь предложенные изменения в окне сравнения.
5. Только при желании подтверди применение. До записи создаётся резервная копия в ~/LocalChat_Backups/.
Важно: предложения локальной модели могут содержать ошибки. Просматривай изменения и сохраняй собственные копии важных проектов. Программа не запускает полученный код автоматически.
Локальные данные и приватность
- Запросы идут на 127.0.0.1:1234, без обращения к OpenAI API.
- По кнопке «Сохранить чат» переписка записывается в папку Chats/ рядом с программой (или в выбранное место).
- Папка Chats/ исключена из Git с помощью .gitignore.
- Если прикрепить исходный код, он передаётся локальной модели LM Studio.
- Результаты зависят от выбранной модели и настроек LM Studio.
Проверка
Запусти модульные проверки стандартной библиотекой:
python -m unittest discover -s tests -v
Они не требуют запущенного LM Studio; реальное взаимодействие с сервером нужно проверить отдельно.
