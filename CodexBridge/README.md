# CodexBridge 5.0 — архив исходников

**CodexBridge** — плагин для стандартного Python IDLE (Windows), работающий с установленным и авторизованным **Codex CLI**. Это отдельная программа; **LocalChat / LocalBridge / LM Studio для неё не требуются**.

## Что лежит в этой папке

- [`CodexBridge.py`](CodexBridge.py) — исходный код расширения IDLE, версия `5.0.0 (2026-10-24)`.
- [`install_CodexBridge_v5.py`](install_CodexBridge_v5.py) — автономный установщик; сам содержит полный код расширения, создаёт резервные копии перед заменой.
- [`test_CodexBridge_v5.py`](test_CodexBridge_v5.py) — **демонстрационный** файл с намеренным `ZeroDivisionError` для проверки диагностики. Он **не является успешным автоматическим тестом**, при запуске отдельно ожидается traceback.

## Восстановление / установка

1. Установи Python с IDLE и Codex CLI; авторизуй CLI через ChatGPT.
2. Скачай `install_CodexBridge_v5.py`.
3. Открой его в **том IDLE, который хочешь настроить**, и нажми **F5**.
4. Подтверди установку и полностью перезапусти IDLE.

В нашем предыдущем окружении плагин находился по пути:
```text
D:\Python\Lib\idlelib\CodexBridge.py
```
Точное место зависит от установки Python. Рабочий файл можно найти в Python с помощью `import idlelib; print(idlelib.__file__)`.

## Функции версии 5.0

- Чат с Codex прямо в IDLE; копирование переписки.
- Анализ исходника и предложение исправлений с просмотром diff перед применением.
- Проверка синтаксиса, запуск текущего буфера Python и подсветка строки ошибки.
- Навигатор функций, классов и методов.
- Проводник файлов и дисков.
- Резервные копии перед применением исправлений; откат правок IDLE.

## Важно

Это **архив последней собранной нами версии 5.0**, а не подтверждённая копия файла, который сейчас установлен на пользовательском компьютере. Если в Windows позднее были локальные исправления, их следует сохранить отдельно перед переустановкой.

Синтаксис файлов проверен; совместимость с конкретной установкой Windows/IDLE и работа с реальным Codex CLI требуют локальной проверки. Запуск Python-кода в плагине не является песочницей: запускай только доверенные программы. Не публикуй токены, частные исходники, журналы чатов или резервные копии.
